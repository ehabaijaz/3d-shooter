# A random 3D Shooter
This is a basic 3D shooter with a dark mode option so i could submit it to the 3AM YSWS.

# Controls
WASD: Movement 
Spacebar: Jump
E: Switch between 2 guns-> a laser gun and a long range rifle which feel unique.
F: DARK MODEEEEEEEEEEEEEEEEE
Also theres a bunch of sounds..

# Stuff this project taught me
- This project taught me about Autoloads which is very cool and very useful.
- This project taught me about 3D game dev which I'm getting the ropes of. 
- This project taught me about a very interesting way to create a shooting and hit mechanic I mean usually you'd think that you would have to create a projectile that moves straight 
- and if you collide with that you lower health and blah blah and its all very manual and straightforward and yeah thats possible but like idk i used particle animations and area3ds to 
- emulate the effect of shooting and getting hit, theres admittedly not that much game juice but yknow its faster! i guess
